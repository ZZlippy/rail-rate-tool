Versions

Each quote date uses one file: the copy with the latest internal last-saved time (from the file's own properties, not the download time). The price list shows how many other copies were ignored.

Departure Date Rule

Lookup cards and the Departure Date timeline price each departure at the latest quote published on or before it. If a sold-out (舱位) notice for that departure came first, the last price before the notice is used. Capacity notes appear in card and price list remarks only.

Departure Months

A price listed for two months, such as 9-10月, counts under both. The menu opens on the latest month in the data.

Base Rate and All-In

All-in adds the fees a sheet lists for this destination: the COC box pickup charge in the origin city and any fee marked 不含. The 不绕区 surcharge is added only when ticked under More Filters.

Exchange Rate

USD comes from the sheet where given. RMB-only prices use the RMB/USD rate implied by that day's own sheets (about 6.68–6.85 in this period).

Updating

Add the new export folder to Rail Freight, run rail-price-tool/extract.py, then ask Claude to republish. New destinations are added in the script's DESTINATIONS list.
